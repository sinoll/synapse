## 修改 php.ini 配置大文件上传 以便视频上传

### 配置大小关系公式

修改时请确保大小关系满足以下逻辑，否则可能导致大文件上传失败：
memory_limit (内存限制) > post_max_size > upload_max_filesize

#### 核心配置项
• file_uploads = On
    • 作用： 是否允许通过 HTTP 上传文件。
    • 注意： 必须保持为 On，如果设为 Off，整个上传功能将被完全禁用。

• memory_limit (内存限制)
    • 作用： 核心作用是限制单个 PHP 脚本在运行过程中可以申请的最大内存总量。
    • 注意： • 意味着每一个并发的 PHP 请求/进程都可以用满 128M 内存。如果你的 PHP-FPM 开启了 50 个子进程，在极端高并发下，PHP 总共可能消耗 50 * 128M = 6.4G 的内存。因此，设置此值时需结合服务器的总内存和并发量进行估算
• post_max_size = 8M
    • 作用： 允许通过 POST 请求提交的所有数据的最大总体积（包括文件和表单里的其他文本字段）。
    • 注意： 必须大于或等于 upload_max_filesize。如果要支持同时上传多个文件，它应该明显大于单个文件的限制。
• upload_max_filesize = 2M
    • 作用： 允许上传的单个文件的最大体积。
    • 注意： 默认通常是 2M，如需上传大文件，必须调大此参数（例如 50M）。

• max_file_uploads = 20
    • 作用： 单个请求中允许同时上传的最大文件数量。

#### 核心超时配置
• max_execution_time = 30
    • 作用： 单个 PHP 脚本允许运行的最大 CPU 时间（单位：秒）。
    • 大文件上传： 默认 30 秒。如果要上传几百兆的大文件，且网络较慢，必须将此值调大（例如 300 表示 5 分钟，设为 0 则表示不限时）。
• max_input_time = 60
    • 作用： 脚本解析输入数据（包括 POST 数据、GET 数据和文件上传）允许花费的最大时间（单位：秒）。
    • 大文件上传： 这个参数对大文件上传至关重要，它接收文件流的时间如果超过该限制就会报错。建议设置为与 max_execution_time 相同，或直接设为 -1（表示使用 max_execution_time 的值）。


### 最佳实践与调整建议
• 常规 Web 应用程序通常设置 128M 或 256M 即可满足绝大多数需求。

• 临时提高内存：如果只有某一个特定脚本（如导出 Excel、处理大图）需要大内存，不建议全局调大 
在脚本文件中增加 代码

 // 临时允许该脚本使用 2G 内存
ini_set('memory_limit', '2048M');
ini_set('post_max_size', '1768M');
ini_set('upload_max_filesize', '1512M');
//临时调高超时设置
ini_set('max_execution_time', '300');
ini_set('max_input_time', '600');

对于 Yii2 项目，最合适的做法是把 FFmpeg 路径配置放在配置文件中，再通过一个独立的服务类统一调用，不要把这段代码直接写进 web/index.php 或每个控制器。

这样 Windows 本地开发使用 D:\software\ffmpeg\bin\ffmpeg.exe，Linux 部署使用 /usr/bin/ffmpeg，控制器和业务代码都不需要关心操作系统。

下面按你使用 Yii2 的情况给出一套可直接落地的方案。
一、推荐的文件结构
以 Yii2 Basic 项目为例：
项目根目录/
├── config/
│   ├── web.php
│   └── ffmpeg.php
├── services/
│   └── FfmpegService.php
├── controllers/
│   └── VideoController.php
├── web/
│   └── index.php
└── ...


如果你使用的是 Yii2 Advanced，可以将服务类放到 common/services/，供前台和后台共用。
二、第一步：在 config/params.php 配置路径
Yii2 Basic 项目通常已经有 config/params.php 文件。

打开它，添加 FFmpeg 配置。保留原有参数，只增加 ffmpegPath：
<?php

return [
    // 其他已有参数保留

    'ffmpegPath' => PHP_OS_FAMILY === 'Windows'
        ? 'D:/software/ffmpeg/bin/ffmpeg.exe'
        : '/usr/bin/ffmpeg',
];


这里不建议立即执行 is_file() 并抛出异常，因为某些环境可能暂时没有安装 FFmpeg，而你不一定希望整个 Yii2 应用因此无法启动。

确认 config/web.php 已经加载该参数文件。Yii2 Basic 默认通常有类似配置：
'params' => require __DIR__ . '/params.php',


如果已经存在，就不需要重复添加。
三、第二步：创建 services/FfmpegService.php
在项目根目录新建 services 目录，再创建 FfmpegService.php。

文件路径：
services/FfmpegService.php


代码如下：

<?php

namespace app\services;

use Yii;
use RuntimeException;

class FfmpegService
{
    /**
     * 获取 FFmpeg 可执行文件路径
     */
    public function getBinaryPath(): string
    {
        $ffmpeg = Yii::$app->params['ffmpegPath'] ?? '';

        if ($ffmpeg === '' || !is_file($ffmpeg)) {
            throw new RuntimeException(
                'FFmpeg 不存在，请检查 config/params.php：' . $ffmpeg
            );
        }

        return $ffmpeg;
    }

    /**
     * 获取 FFmpeg 版本信息
     */
    public function getVersion(): array
    {
        $ffmpeg = $this->getBinaryPath();

        $command = escapeshellarg($ffmpeg)
            . ' -version 2>&1';

        $output = [];
        $returnCode = 0;

        exec($command, $output, $returnCode);

        if ($returnCode !== 0) {
            throw new RuntimeException(
                'FFmpeg 执行失败：' . implode("\n", $output)
            );
        }

        return $output;
    }
}



这段代码就是之前那段路径判断逻辑的合适归属：由服务类负责获取和验证路径，配置文件只负责提供路径。

注意：PHP 必须启用 exec()，且该函数没有被 disable_functions 禁用。
四、第三步：在控制器中调用
例如创建 controllers/VideoController.php：
<?php

namespace app\controllers;

use Yii;
use yii\web\Controller;
use app\services\FfmpegService;

class VideoController extends Controller
{
    public function actionTestFfmpeg()
    {
        $service = new FfmpegService();

        $version = $service->getVersion();

        return $this->renderContent(
            '<pre>' . htmlspecialchars(
                implode("\n", $version),
                ENT_QUOTES,
                'UTF-8'
            ) . '</pre>'
        );
    }
}


启动 Apache 后访问：
http://localhost/index.php?r=video/test-ffmpeg


如果 FFmpeg 正常运行，页面会显示版本信息。
