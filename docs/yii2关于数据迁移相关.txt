命令                                      作用说明                                            示例场景
php yii migrate/safeDown                回退最近一次应用的迁移（最常用）                        刚执行 migrate 错了，想马上撤销
php yii migrate/down 3                  回退最近 3 回退最近一次应用的迁移（最常用）              连续错了几个迁移
php yii migrate/down                    回退所有已应用的迁移（小心！清空迁移历史）               测试环境重置数据库
php yii migrate/redo                    回退最近一次 + 立即重新应用（redo = down + up）         测试迁移的 up/down 是否对称
php yii migrate/redo 2                  redo 最近 2 次     
php yii migrate/to mXXXXXX_create_table 回退/应用到指定迁移（自动处理中间的）                     想跳回某个历史版本
php yii migrate/to 20250116_040000      用时间戳指定（不带 m 前缀也行）

yii migrate/fresh 						刷新迁移
