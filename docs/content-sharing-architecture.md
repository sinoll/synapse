# Synapse / 突触 （暂定名）
神经元与另一个神经元、肌肉细胞或腺细胞之间进行信号传递的连接部位，是神经系统中细胞彼此“交接信息”的关键位置。它是一个名词，复数形式是 synapses。



一个个人内容管理网站。内容包括  博客 图集 瞬间(微博) 短视频 （内容阅读有严格的权限）。  
站点和站点之间 可以聚合 , 关注(输入另一个站的网址后) 在自己网站可见 人家授权的信息 在自己的站点也可以查看 也可以跳转到原文。 自己的内容发在自己的站点上，别人看见后可以引用或二创后转发到自己的网站。

**自己为自己发布的内容负责，转发的人为自己转发的内容负责。**  每个人或站点就像一个网络节点，更像两个神经元的交汇点 **Synapse**



# 内容分享基础架构

## 内容表

- `post`：内容统一主表，保存作者、标题、类型、发布状态、可见级别和时间；类型字段为字符串，后续新增类型不需要修改数据库字段定义。当前类型值为 `blog`、`images`、`moment`、`short_video`。
- `blog`：博客正文和摘要。
- `images`：独立图片集的图片明细，每张图片一行，保存所属 `post_id`、图片标题、图片地址、说明和排序；一个图片集主记录可以关联多张图片，与博客没有关联。
- `moment`：短动态；保存标题、正文 HTML 与缩略图路径 `thumb`。缩略图不提供单独编辑入口，每次保存时由代码自动取正文首张图片生成，正文图片更换或删除后随之更新，无图片时使用默认封面。
- `short_video`：视频元数据、存储路径、封面和时长。

`post.visibility` 控制博客、图片集、瞬间和短视频：`0` 仅作者可见、`1` 已登录用户可见、`2` 公开访问（发布表单默认）。

四类内容通过 `post` 主表统一记录，并由各自详情表保存专属字段；详情表通过 `post_id` 关联主表，主表关联现有 `user` 表。图片集与其图片明细是一对多关系。

## 应用

主站采用 Yii2 Advanced 模板的 `frontend` 应用。登录用户可通过 `/blog/create`、`/images/create`、`/moment/create`、`/video/create` 等类型专属入口创建记录；匿名访问创建入口会被重定向到登录。图片集支持多图上传、追加与移除。

## 初始化数据库

确认 `common/config/main-local.php` 的连接指向目标库后，在项目根目录执行：

```powershell
php yii migrate --migrationPath=@console/migrations
```

迁移采用 `safeUp`，每张表对应一个迁移文件（`m261016_000002` 至 `m261016_000006`、`m261016_000011` 至 `m261016_000012`），按依赖顺序先建 `post`，再建各类型详情表与标签表。迁移只创建新表、索引和外键，不更改现有用户表。回滚会按相反顺序删除这些表及其数据。
